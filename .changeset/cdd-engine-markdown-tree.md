**The contract plane's ONE document model — identity and location separated (P21 §7.5).** Every registry element now carries two facts instead of one: its `anchor` stays the element's IDENTITY (the schema property name, the `required[]` key, the skeleton truth-table key, the lint lookup key, the `field:` of a finding) and a new `selector` carries its LOCATION — a composable query over the new `MarkdownTree` (`frontmatter` / `heading` / `table` / `row` / `cell` / `list` / `taskField` / `taskStep` / `graphEdge` walks, an optional `match` and a `when` guard). Consumer-visible surfaces are byte-identical: `cdd schema get <type> --output json` and `--output skeleton` render the same bytes as before, and the 21 judgment rules keep their findings.

The four doc types, the home extractors and the 21 invariant strategies now read one tree — `mdast` with the gfm + front-matter extensions, one parse per document — instead of hand-written line scans. A resolved node is line-faithful (`text` is the node's raw line, `bare` the same line with its `inlineCode` spans removed), so the declared value shapes and the citation boundary both run on node text. The block grammar (`task-blocks.ts`) is a facade over the tree, the canonicalize pass runs once per document through a `RowSource`, and the skeleton round-trip is pinned: bytes → tree → headings, table headers and element order read back unchanged. Retired with the scanning layer: the line-level heading-rank, `|`-split table, graph-edge and backtick first-to-last primitives.
