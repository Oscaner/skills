**The consumer-side obligations of the same contract: self-review, the approval gate, and who may write a document.** The four self-review questions are registered once in the engine's skill-anatomy contract — evidence before assertion, the two-axis check (repo standards and the declared spec), fixing in the same round what the self-check finds, and a self-check that never substitutes for the downstream review — and `cdd-spec-writer` and `cdd-plan` now carry a pointer to them on their `self-review` node instead of restating the text. `cdd-design` gains no node: its document path runs through `cdd-spec-writer`, so the registered obligation reaches it.

The approval gate is stated where the dispatch actually happens: any flow that dispatches the first NEXT-loop round after a self-review — `cdd-spec-writer` (spec review), `cdd-plan` (plan review) and `cdd-dev` (the first implement / review / fix round) — presents the artifact together with the self-check conclusion and stops for the author's explicit approval before dispatching. Backfilling the charter's tables does not skip it: the result is presented again and approval is awaited again. One obligation, three entries, no second stop point and no approval-state file.

Document writing authority is split in three: shaping an overall, spec or plan (new writing, restructuring, section moves, the parent-charter backfill) belongs to the orchestrator's own session and is never delegated wholesale to a child agent; a dispatched round may amend the content face of a spec or plan (facts, file lists, steps, acceptance detail, cited line numbers) and that right now reaches the docs-fix shell too; the structure face — the set of task ids or any task's `DependsOn` set — belongs to the orchestrator and is judged as a hard violation when a round changes it. The submission line states that the document was written in the orchestrator's own session.

No skill's digraph changes with any of this: the obligation sentences and pointers join existing nodes, and the contract's section registry gains only the registered obligation entries.
