`cdd board` now prints each round's `notes` as a count. Every round's note bodies used to be inlined into its progress cell, so a phase board's bytes were mostly prose; the token now stops at `notes +M`, keeps that count exactly where it sat, and appends the same folded rows under a new bool flag, `--notes` (no counted variant). A board rendered with `--notes` is byte-identical to the previous output, a board rendered without it carries the count and no body, and neither form changes the token order (`verb · body · mark · +N · downgrade note · notes +M`) or the one-line-per-token shape.

The closure reading that `doc-contract` receives is now a reader of its own (`ClosedDocument`), enumerated through the same identity index the command preamble already builds; the fence-aware markdown reader and the path grammar moved onto the rule plane — those three legs keep judging.

The pin gate itself retires whole. A document's backticked path, symbol and test title are no longer judged: the criterion row that named the gate leaves `CRITERIA_ROWS` (the rubric renders one row shorter, and the row `face` vocabulary loses its `test` value), a round no longer injects warn rows into a review's `findings`, and the review criteria table carries no engine-authored lens. No flag is removed — `cdd review`, `cdd plan` and the handoff schema are unchanged.

The census face retires whole, grammar included: `contract/census.ts` leaves the tree with its one reader — the `measure-literal` shape row, whose span read of a `census:<id> = <n>` form was the module's only caller — so no judgment reads a `census:` form any more, and a document's counts are writing convention rather than a machine-checked form. The rule declaration surface's seat vocabulary loses its `corpus` value in the same batch: a doc row now declares `dispatch` · `close`, a ledger row `ledger`. The count sentence the spec review rubric and the two authoring skills teach retires its census half with the row — a count carries no mechanical face, a bare integer beside a count unit is the writing convention rather than a refusal, while an arithmetic over live counts is still refused — and the shape gate's single zero-candidate reading passes to `line-coordinate`, so a document whose face map places nothing is still reported instead of read as clean. The retired corpus arms leave their rules with the fixtures they had (a violation reports, a neighbour stays silent, an empty candidate set is measured).

The generated-product comparison keeps one execution face. A diagram source is no longer judged against the artifact committed beside it by a test: `pnpm run emit:check` compares each source with a fresh render of itself, one assertion per leg — the citation multiset and its count, the source's revision pin against the artifact's evidence block, the copy cells, a source's node `tag`, and the retired command spellings (absent from the render). The engine's `DiagramTwin` product readers retire with their only callers, and both architecture artifacts are re-rendered so their embedded engine citation follows the `init` block into `face/cli.ts`. No published file moves — `dist/` and `templates/` are untouched — and no artifact is edited by hand; what changes is where the products are compared, and the artifacts remain the same products, now judged beside their sources.
