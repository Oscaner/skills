refactor(engine) + docs(kairos): P7 engine doc-tooling — the evaluation face's commit-sha vocabulary retires engine-wide, the single-source-of-truth discipline is enforced at every decision surface, and the consumer prose re-anchors (pending — no publish):

- **The commit-sha evaluation face retires** (breaking) — the engine no longer carries a commit identity anywhere in its review/fix flow. `GitClient` collapses from six seams to two (`topLevel`/`isClean`; `revParseHead`/`addAll`/`commit`/`log` deleted), the `BranchRef` class and its `session/branch-ref.ts` module are deleted, `Route.review` drops its `{base,head}` range, `AuditTarget`'s branch leg collapses to `{kind:"branch"}`, and the `--head` flag plus the `"sha"` channel value type retire. The branch review judges the live tree, scoped by the engine-injected `BASE_BRANCH` (read from the base artifact's branch name), never a stored range.
- **The prompt data-plane tokens retire** — `INPUT_RANGE`/`INPUT_PLAN`/`FIX_BASE`/`OUTPUT_BRIEF` leave the token registry and every mode shell; `BASE_BRANCH` joins. The review reads a single doc anchor (`INPUT_DOC`) and a fresh wave-brief mirror (`INPUT_WAVE_BRIEF`), the brief renders the full plan mirror (task sections + `## Constraints`), and every dispatch re-extracts it unconditionally (the `exists`-guard reuse path is gone). `TEMPLATE_PROMPT.$version` records the data-plane change (6 → 7).
- **The handoff carrier contracts** — the `commits` / `changes[]` carrier fields (`COMMITS`/`CHANGED_FILE` schema nodes, `CarrierValue` keys, `Round.commits`, `scope_base`, `snapshotSha`) are all deleted; the return block is exactly two lines (`status` + `artifacts`). The write plane and the read-back validator judge every field the same way: a non-declared or engine-reserved (engineOnly) field is DROPPED (never a BLOCK), semantic errors (`required`/type/enum/length) still BLOCK — one disposition per field, zero second-arbiter friction.
- **The decision surfaces read the live fact, never a copy** — the round verdict reads the recorded round carrier (a rejected round whose stale draft lingers on disk returns null, so a `BLOCKED` round never renders a contradictory `next:` line); the doc line keys by its line-type constant (`"spec"`/`"plan"`, aligned with the branch line's `"branch"` key) at both derivation points, so a moved argv path never forks the same line into two ledger rows.
- **kairos consumer prose re-anchors** (patch) — `cdd-dev` drops the I7 gate line and rewrites the branch-review node to the single-`--plan` literal (zero merge-base/rev-parse/`--base --head`), `cdd-plan` states the constraints channel via the wave-brief mirror, and the README family carries zero retired-lexicon residual (pinned by a consumer-face grep sweep).
- **Preserved by construction** — the doc-contract gate semantics, `base` set/get, clean-tree gate, and the `doc_revision` content fingerprint are untouched; only the sha/brief/round/key/field decision surfaces move. The wave line's phase derivation is consolidated, not altered: the wave gate and the lifecycle frame frontier now read one source (`Ledger#waveLinePhase`) — the router decision table itself (`next.ts`) stays untouched.
