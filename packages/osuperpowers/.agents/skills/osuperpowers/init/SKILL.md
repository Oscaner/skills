---
name: init
description: Parameterized initialization tool. `init router` initializes the superpowers self-check table; `init harness` installs per-harness configuration.
---

<!-- osuperpowers-version: 0.1.1 -->

Dispatch by parameter: `spor` -> execute [router.md](router.md); `harness` -> execute [harness.md](harness.md).
No parameter -> list available targets (spor / harness) for user selection.
