# os-engineering Cursor wrapper

占位 — the Cursor wrapper for this plugin is **generated by emit** into
`cursor-plugins/os-engineering/.cursor-plugin/plugin.json` from
`marketplace/source.json` (`cursor.displayName` + `cursor.skills`).

Do not hand-edit the generated wrapper. After changing `source.json`, run:

```bash
pnpm run emit:marketplace
pnpm run validate
```
